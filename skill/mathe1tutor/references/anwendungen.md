# Anwendungen je Thema (für das PRAXIS-Feld)

Kurz, konkret, mit der Größe, auf die es ankommt. Keine erfundenen Messwerte.

| Thema | Anwendung |
|---|---|
| Induktion, Summenformeln | Ratenzahlungen/Zinseszins: geometrische Summe $1+q+\dots+q^n=\frac{1-q^{n+1}}{1-q}$ |
| Folgen, Grenzwert | Newton-Abkühlung $T(t)\to T_0$; Messwert als Grenzwert immer genauerer Näherungen |
| Reihen | Leibniz-Fehlerabschätzung: wie viele Glieder für 3 Dezimalstellen; Exponentialreihe im Taschenrechner |
| komplexe Zahlen | Wechselstrom-Zeiger, Drehstrom (3 Phasen um $\frac{2\pi}3$ verdreht); Multiplikation = Drehstreckung |
| Vektoren, Skalarprodukt | Arbeit $W=\boldsymbol F\cdot\boldsymbol s$; Projektion einer Kraft auf eine Richtung |
| Kreuzprodukt | Drehmoment $\boldsymbol p\times\boldsymbol f$; Geschwindigkeit bei Rotation $\boldsymbol v=\boldsymbol\omega\times\boldsymbol x$ |
| Ebenen, Hesse | Abstand eines Punktes von einer Fläche (Toleranz, Kollision) |
| Zwischenwertsatz, Nullstellen | Wien'sches Verschiebungsgesetz $e^{-x}+\frac x5-1=0$ |
| Ableitung | Momentangeschwindigkeit $v=\dot s$; Empfindlichkeit eines Messgeräts |
| Linearisierung, Fehlerrechnung | Wheatstone-Brücke: Messfehler minimal bei $a\approx\frac l2$; Pendel/Federschwinger $\nu=\frac1{2\pi}\sqrt{c/m}$ |
| Polynome | Biegelinie $w(x)=\frac q{24EI}(l^3x-2lx^3+x^4)$; Stefan–Boltzmann $E=\sigma T^4$ |
| rationale Funktionen | Luftdruck $p(h)\approx p_0\frac{31-h}{31+h}$, van der Waals; PBZ für Laplace-Rücktransformation |
| exp, ln | Abkühlung, Wachstum/Zerfall, Wärmestrom durch Rohrwand $\phi=\frac{2\pi l\kappa\Delta T}{\ln(D/d)}$ |
| Hyperbelfunktionen | Kettenlinie (Seil, Kette) $y=h+c(\cosh\frac{x-a}c-1)$ |
| Winkelfunktionen | harmonische Schwingung $A\sin(\omega t+\alpha)$, Zykloide bei Verzahnungen, Snellius |
| L'Hospital | Planck'sches Strahlungsgesetz an den Rändern |
| Taylor | Näherungen $\sin x\approx x$ (Pendel), Fehlerschranke; numerische Ableitung |
| Newton-Verfahren | Wurzelberechnung im Rechner $x_{n+1}=\frac12(x_n+\frac k{x_n})$ |
| Extrema | minimale Wellengeschwindigkeit; Optimierung von Materialverbrauch |
| Krümmung | Kurvenradius im Straßen-/Bahnbau |
| partielle Ableitungen | Wärmeleitungsgleichung, schwingende Saite |
| Integral | Arbeit einer Feder $\frac{cl^2}2$; Fläche, Mittelwert eines Signals |
| uneigentliche Integrale | Fluchtgeschwindigkeit $\approx11$ km/s; Normalverteilung |
| numerische Integration | Fläche aus Messreihe (Trapez-/Simpsonregel) |
| Bogenlänge, Schwerpunkt, Volumen | Kabellänge, Ellipsenumfang; Schwerpunkt eines Blechs; Rotationskörper |
| DGL 1. Ordnung | Abkühlung, Luftdruck $p'=-kp$ |
| DGL 2. Ordnung | Feder-Masse-Dämpfer: Kriechfall, aperiodischer Grenzfall, gedämpfte Schwingung |
